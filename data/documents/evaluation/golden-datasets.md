\# Golden Datasets



A golden dataset contains representative questions with expected evidence and expected answers.



Golden cases should cover different categories and difficulty levels.



Cases should include direct questions, paraphrases, cross-document questions, and queries that distinguish between closely related concepts.



Expected documents define the evidence required to answer a case.



Golden datasets should remain stable when comparing application versions.



Changes to the golden dataset should be reviewed separately from changes to the retrieval or generation system.
